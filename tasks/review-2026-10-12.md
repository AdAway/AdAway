# October Product Review And Release

Baseline: `59b7e131cc3acdec47b8bec399a07a121de9f87a` on `master`.
Working branch: `codex/october-release-review`. Target: Android `13.5.2b` / `130502`.

## Definition Of Done

One bounded first-party review, an evidence-backed bug register, verified URL-based
filter subscriptions, consolidated automated and emulator checks, a protected PR,
and a signed downloadable release candidate. This is not a promise that every OEM,
third-party filter, website, rooted device, or dormant native source is bug-free.
Stable release approval requires physical-device testing; emulator evidence cannot
substitute for it.

## Signing Migration

The owner confirmed the old key is unavailable and authorized a new identity.
Android signer SHA-256:
`9bf3a40102638ed9271f4dea6225a2d66e5d2c5f3e5204cc125376288f7f9595`.
The new Android, update-manifest, and tag keys are outside the repository in a
permission-restricted local directory; eight corresponding GitHub secrets are configured.
Private material is never committed. The owner should retain an encrypted off-device
backup; the local protected copy alone is not disaster recovery.

Existing 13.5.0 and June 13.5.1 builds use different keys: export configuration first,
uninstall the old app, install the new APK, restore configuration, then update filters
and grant VPN consent. This signing boundary cannot be bypassed as an in-place update.

## Explicit Remaining Boundaries

- Physical Android/OEM smoke, cellular/Wi-Fi handoffs and older-device descriptor
  behavior are not proven by API 34 emulator tests.
- App-authorized root installation/restore remains unverified; this candidate's
  primary path is non-root VPN. Root shell unit tests are not device proof.
- DNS blocking supports domain/hosts rules and representable ABP domain rules, not
  browser cosmetic/path/scriptlet filtering. A filter URL cannot change that boundary.
- Dormant tcpdump vendor code has eight existing CodeQL alerts, is outside the APK,
  and is not rewritten or represented as remediated by this release.
- iPhone installation is out of scope: an Android APK does not run on iOS.
